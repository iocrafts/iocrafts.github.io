IOcrafts is an independent open-source effort that builds small, scriptable command-line tools for developers and operations teams.

## Projects

- [**Hsftp**](/projects/hsftp/) — a Haskell SFTP command-line client, published on [Hackage](https://hackage.haskell.org/package/hsftp) under the BSD-3-Clause license.
- [**Puppetchef**](/projects/puppetchef/) — YAML-driven browser automation on Puppeteer, published on [npm](https://www.npmjs.com/package/puppetchef) under the MIT license.

## Contact and Contributions

All source code lives on [GitHub](https://github.com/iocrafts). Bug reports, feature requests and pull requests are welcome in each project's issue tracker.
The maintainer can also be reached on [LinkedIn](https://linkedin.com/in/mauriziodusi).
